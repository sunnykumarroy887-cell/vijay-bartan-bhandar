Tracking Instructions

  • Enquiry भेजते ही मिला Booking Number संभालकर रखें — tracking के लिए यही जरूरी है।
  • Tracking page पर Booking Number और registered Mobile Number दोनों सही-सही भरें।
  • आपको Pending, Confirmed, Issued, Return Pending और Completed जैसे हर चरण का update दिखेगा।
  • आपकी जानकारी सुरक्षित है — details केवल सही registered mobile number match होने पर खुलेंगी।
STATUS GUIDE
📌

Booking Status

Pending — आपकी enquiry प्राप्त हो गई है।

Confirmed — आपकी booking owner द्वारा confirm कर दी गई है।

Issued / Return Pending — Booking के अनुसार सामान जारी या वापसी की प्रक्रिया में है।

Completed — आपकी booking पूरी हो गई है।
