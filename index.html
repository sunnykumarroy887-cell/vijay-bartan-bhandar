Tracking Instructions

  • Booking submit करने के बाद Booking Number को सुरक्षित रखें।
  • Booking track करने के लिए Booking Number + Mobile Number दर्ज करें।
  • आप अपनी Booking का Pending, Confirmed, Issued, Return Pending और Completed status देख सकते हैं।
  • Booking details केवल matching mobile number के साथ दिखाई जाएंगी।
📌

Booking Status

Pending — आपकी enquiry प्राप्त हो गई है।

Confirmed — आपकी booking owner द्वारा confirm कर दी गई है।

Issued / Return Pending — Booking के अनुसार सामान जारी या वापसी की प्रक्रिया में है।

Completed — आपकी booking पूरी हो गई है।
